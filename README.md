## 🔷 Overview

**Tetris 2.0** is a modern Python/Pygame implementation of the classic Tetris game. It includes a full menu system, gameplay mechanics, scoring, collision detection, pause/resume, and a clean user interface.

Developed as part of my **OCR A-Level Computer Science NEA**, this project demonstrates object-oriented programming, game development principles, and user-focused software design.

---

## ✨ Features

- Interactive menu system
- Smooth block movement and rotation
- Collision detection
- Line clearing and scoring
- Next-piece preview
- Pause and resume
- Game over detection
- Clean and intuitive user interface

## 🎮 Controls

| Key | Action |
|------|--------|
| ← / → | Move piece left/right |
| ↓ | Soft drop |
| ↑ | Rotate piece |
| P | Pause / Resume |
| Any Key | Restart after Game Over |
| Esc / Q | Quit game |

---

## 📊 Scoring System

| Action | Points |
|--------|--------|
| Single Line | 100 |
| Double Line | 300 |
| Triple Line | 500 |
| Soft Drop | +1 per move |

## 💾 High Score Saving
